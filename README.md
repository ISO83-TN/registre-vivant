# Registre Vivant — démonstration

Démonstration publique de Registre Vivant (NT Ingénierie) : maquette d'exploitation 3D d'un bâtiment existant, unifilaires, QR codes et suivi des vérifications périodiques.

Toutes les données sont **fictives** (« Groupe scolaire Les Tilleuls »). Aucune donnée client.
